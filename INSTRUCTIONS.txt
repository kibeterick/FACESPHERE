================================================================================
                              TROUBLESHOOTING
================================================================================

🚨 GOT ERRORS? Follow this process:

STEP 1: Run Diagnostics
    diagnose_system.bat
    → Shows exactly what's wrong
    → Recommends solutions

STEP 2: Read the Fix Guide
    COMPLETE_FIX_GUIDE.md
    → Comprehensive solutions
    → Multiple paths to success
    → Step-by-step instructions

STEP 3: Try Recommended Solution
    Usually: install_working.bat
    → Works 99% of the time
    → Skips problematic packages

Common Issues:

Problem: CMake error during installation
Solution: → Read COMPLETE_FIX_GUIDE.md (Path 1)
         → Or run: install_working.bat
         → System works without face_recognition!

Problem: Installation fails
Solution: → Run: diagnose_system.bat
         → Install packages one by one
         → Skip optional packages

Problem: Port 5000 already in use
Solution: → Edit flask_app.py, change port to 8080
         → Or stop other service using port 5000

Problem: Face recognition not working
Solution: → This is EXPECTED if you used install_working.bat
         → See: CMAKE_INSTALLATION_GUIDE.md to enable
         → Or skip it - 90% functionality without it

Problem: Voice not working
Solution: → Use web interface instead
         → Or install pyaudio separately

Problem: Module not found
Solution: → Run: install_working.bat again
         → Or: pip install <module_name>

Problem: System won't start
Solution: → Run: diagnose_system.bat
         → Check Python installation
         → Verify packages installed
